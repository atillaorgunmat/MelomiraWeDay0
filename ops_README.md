# ops_README.md — v4.5 (Operator Quick Path)

1) Persist clarifiers → GUIDANCE FORM `clarifier_round`.  
2) Harvest assumptions → GUIDANCE FORM `assumption_register_ops` (commit).  
3) Keep a single QUESTION_BANK with statuses (CANDIDATE/FROZEN/...).  
4) SELECT‑ORG picks a tiny nucleus (2–3 nodes).  
5) GUIDANCE emits `pro_request` + `q_patch` (with provenance + assumptions).  
6) Echo‑Forward to AUTO: VERIFY → APPLY.  
7) Confirm with AUTO‑READ; log decisions via `decision_log_ops`.
